# HaxBall Custom Client

Cliente de escritorio de HaxBall con temas, estadísticas, ventana flotante, modo espejo, avatares animados y más.

## Descargar

Andá a **[Releases](../../releases/latest)** y bajá:

- **`…-setup.exe`**: instalador (recomendado). Después se actualiza solo desde el menú **Actualizar** del cliente.
- **`…-portable.exe`**: se abre sin instalar.

Si Windows muestra "Windows protegió su PC", tocá **Más información → Ejecutar de todas formas** (el exe no tiene firma de código).
